## Cross-cutting inventory claims and retained decisions

- The independently recomputed Sun inventory matches **388 runtime definition occurrences / 333 distinct names**; the CSV includes lazy wrappers/fallback duplicate definitions and the _fbr_format_entry autoload body; the ztheme entry body is assessed alongside its named implementation. This validates coverage accounting, not execution/profiling of all 388. Low-cost inventory rows are static assessment, not measured hot-path conclusions.
- Zoxide integration runs its guarded load/generation block whenever the binary exists (`30-zoxide.zsh:142`); only some refresh/diagnostic paths depend on execution mode. Fzf initialization requires interactive and empty ZSH_EXECUTION_STRING (`40-fzf.zsh:654`). Do not generalize either path to all shell modes.
- Warm cache observations do not prove zero external startup processes or exactly one fork for all installations. Cold/stale integration caches generate and syntax-validate code; optional tools, generated upstream bodies and host configuration change work. Fixed warm-fork counts require a trace of the actual environment.
- Builtin command -v, source, zstat, read and function dispatch do not inherently fork. Capturing their output may do so; `$(<file)` is a special builtin file read. A bulk shell operation is not a guaranteed single kernel syscall. Generic cost-class labels in Sea are corrected accordingly.
- First-use same-name theme wrappers replace themselves after loading (`25-theme.zsh:61–78`), so permanent wrapper overhead is not established. Fresh ztheme color-depth detection cannot be replaced by a startup snapshot without environment-change parity.
- Brew search may run four captures (formula/cask search and formula/cask info), not three; version/header work is conditional. Existing batching should remain.
- Full raw files are O(total path bytes) on disk; retained arrays are O(total record data). This is not a measured resident-memory multiplier or demonstrated RSS saving. Numerical size/sum bounds and integer overflow must be validated before arithmetic-expression aggregation.
- Additional sketches (status reply arrays, terminal-height/repeat helpers, theme-role membership, path/sanitizer captures, socket scale, history/OMZ startup, extra jq consolidation and cache-identity accumulation) remain consumer-profile-first backlog. No separate approved feature changes or numerical speedups attach to these sketches. Model terminal context, safe escaping, public overrides and source discovery before expanding scopes.
- Retain C01 live width checks, C04 ordered completion cache, C05 JSON decoding, C06 bounded slot refill, C07 exact arithmetic color conversion and C08 pure Nix sanitizer conversion. Do not relabel landed work as missing.
- Historical decisions were checked using `git show 5e9ad1d^:docs/performance/decisions.md`: retain registry validation C09; wordcode C10/C11 remains gated; broad terminal-sensitive C08 conversion and C12 export caching have no blanket approval; keep D01 keymap rollback and D02 integration/guard/CGM boundaries. New measured scoped plans do not repeal those decisions.
- Rejected throughout: parallel mutations or secrets, cached secret values, prompt prewarming/hooks, unchecked eval/downloads, weakening ownership validation, dropping native output comparisons, new mandatory rendering runtimes, automatic wordcode and uncontrolled RGB caches. These violate existing scope or safeguards, not missed speedups.
