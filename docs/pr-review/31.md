### Judgement calls

- **Duplicated Code**: the `while true; do trap '…break 100' … done` + `signal_status` scaffold is copy-pasted three times — 60-functions.zsh:545–548, 699–702, 3924–3927 — plus near-identical validate/mktemp/always-cleanup shapes in `dusage` vs `bigfiles`. Extract a shared trap helper.
- **run-tests.zsh:13** `trap cleanup EXIT INT TERM HUP`: trapping INT/TERM means zsh continues to the next suite after Ctrl-C instead of aborting; consider re-raising/exiting in the handler.
- **Trap window nit**: if INT lands between the final loop exit and return (e.g., 60-functions.zsh:835), `break 1000` executes with no enclosing loop → spurious shell error before the status is returned.
- GUIDE.md fbr section still says "checks out" after `_fbr_activate` moved to `git switch` (60-functions.zsh:1124–1136); colloquially true but no minimum-git-version (≥2.23) note was added anywhere.
- `upkg` search backends gained `--` separators (e.g., 60-functions.zsh:2129 npm); supported by apt/brew/flatpak, but npm's `--` semantics are quirky — tests stub these binaries, so live behavior is unverified.
