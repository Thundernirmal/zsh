Tier 0 — fix as soon as possible

CR-01

Top-level command -v nix walks the whole PATH on every shell start

fixed · cab1547 ·#3160-functions.zsh:3782Ox ● · dsV4 ● · Gemini ● · Muse ○severity: High (consensus)

The only startup-time guard in the repo violating AGENTS.md’s $+commands rule — commit d90ed98 converted the rest and missed this one. On nix-less machines it buys a full PATH miss per start; worst case dominates on WSL2-length PATHs (measured 35–416× slower than the hash lookup). Double penalty: full walk, nothing gained.

Fix  if (( $+commands[nix] )); then — one line. Better: move the ~857-line npkg block to an autoloaded helper. Note: test-upkg stubs nix via PATH, so either rehash in tests or document the deliberate exception in AGENTS.md.

CR-02

CI silently diverges from the documented 11-step verification

fixed · 00c87e6 ·#31.github/workflows/checks.ymlOx ● · dsV4 ● · Gemini ● · Muse ●severity: High (unanimous)

Benchmark-script syntax check (step 2) and the final source-smoke test (step 11) are absent from CI; Muse additionally notes check-deps.sh is never executed, there’s no job timeout, and pushes to the active dev branch trigger nothing. Root cause: the sequence is hand-maintained in AGENTS.md, GUIDE.md, and checks.yml.

Fix  Add scripts/run-tests.sh encoding the documented order; make checks.yml call it verbatim; add timeout-minutes and dev-branch/workflow_dispatch triggers.

CR-03

Exported env var can redirect all lazy theme-helper sources

fixed · cab1547 ·#3125-theme.zsh:21Ox ● · dsV4 ○ · Gemini ○ · Muse ●severity: Medium–High

${_ZSH_THEME_MODULE_DIR:-…} honors a caller-exported value, sending every lazy source of the theme libs to an arbitrary directory — an explicit violation of the “fixed to the repository directory, not user-controlled” rule. Contrast 60-functions.zsh:106, which sets its dir unconditionally.

Fix  typeset -g _ZSH_THEME_MODULE_DIR=${${(%):-%N}:A:h} — drop the fallback wrapper.

CR-06

Temp files leak when dusage / bigfiles / npkg index hit signals or failures

fixed · 279ae27·e6d4f06·449721b ·#3160-functions.zsh:545–554 · 674–696 · 3868–3879Ox ● · dsV4 ◕ · Gemini ● · Muse ◕severity: Medium

Ctrl+C during scanning leaves mktemp files orphaned in $TMPDIR (no INT/TERM traps); _npkg_refresh_index leaks .err/.tmp on specific failure paths. Cleanup discipline is inconsistent across the module — elsewhere traps are the norm. (Muse counted a trap here as a strength; Ox and Gemini traced the interrupt paths specifically.)

Fix  setopt localtraps + trap 'command rm -f -- "$f1" "$f2"' EXIT INT TERM; close the _npkg_refresh_index leak paths for parity.

CR-07

Missing -- terminators let hyphen-prefixed arguments parse as options

fixed · 279ae27 #31 · 526dd6f #32mkcd:57 · extract:14–45 · croot:980 · _fbr_activate:1077–1086 · search backends:2081,2255,2376,2462Ox ● · dsV4 ○ · Gemini ● · Muse ○severity: Medium

mkdir -p "$1", the extract unpackers, cd "$root", git checkout "$branch", and apt/brew/npm/flatpak search backends all pass user-controlled strings without --; pacman/paru already do it correctly.

Fix  Add -- before path/file/query parameters throughout; mechanical change, easy to regression-test.

CR-09

Completion registries hand-duplicated from their owners will drift silently

fixed · 526dd6f ·#3266-compdefs.zsh:26–42Ox ● · dsV4 ○ · Gemini ○ · Muse ◕severity: Medium

Theme-name list duplicates the theme registry, the manager list duplicates the upkg whitelist, extract extensions duplicate the extract table. Adding a sixth theme or manager desyncs completion from behavior with no error — a single-source-of-truth violation.

Fix  Derive the lists at load time, or add a drift-detection sync test asserting equality with the owners.

Tier 1 — high-value performance wins

CR-04

Three capability probes fork subprocesses on every startup

fixed · 526dd6f ·#3220-aliases.zsh:10 · 42 · 46Ox ● · dsV4 ● · Gemini ● · Muse ●impact: −2.6 ms (~10% of startup)

ls --color, a 3-process grep pipeline, and diff --color run unconditionally each start to detect flag support — the largest single module cost (20-aliases: 6.3–8.0 ms). The answer essentially never changes.

Fix  Single-process probe: command grep --color=auto -e x </dev/null >/dev/null 2>&1 (exit 1 = supported); gate all three behind presence checks; simplify the ls probe in the lsd-fallback branch.

CR-05

Zoxide fzf-chrome refresh runs eagerly — defeating the lazy-theme invariant

fixed · 526dd6f ·#3230-zoxide.zsh:31Ox ○ · dsV4 ● · Gemini ◕ · Muse ●impact: −2.2 ms on zoxide-less shells + restores laziness

The refresh executes outside the $+commands[zoxide] guard and forces theme registry + palette materialization even in non-interactive shells, git hooks, and zsh -c pipelines — while 40-fzf.zsh:549 correctly gates the equivalent work on interactivity.

Fix  if [[ -o interactive ]] && [[ -z ${ZSH_EXECUTION_STRING:-} ]]; then _zsh_zoxide_refresh_fzf_opts; fi — or defer to first zi via the existing wrapper.

CR-12

fbr branch picker forks 6 subshells per row — 305 ms before the UI opens

fixed · 526dd6f ·#32functions/_fbr_format_entryOx ○ · dsV4 ○ · Gemini ● · Muse ○impact: 190× faster picker launch

Per-row $(_ui_safe_text)/$(_ui_pad) calls mean 288 forks for a 48-branch repo (~1.3 s at 200 branches). Gemini’s pure-Zsh rewrite using printf -v measures 1.60 ms for the same 48 rows. Caution from the cross-review: Ox verified the current [WT] prefix surgery correct for width ≥ 5 — any rewrite must preserve the byte-exact output contract that tests pin.

Fix  In-process formatter setting REPLY via printf -v; keep the fbr-side --accept-nth=5 raw-name selection unchanged; assert row-format equivalence in tests.

CR-13

zhelp catalogue and tips pool build eagerly for on-demand commands

fixed · 526dd6f ·#3265-help.zsh:55–115 · 80-tips.zsh:4–111Ox ○ · dsV4 ● · Gemini ◕ · Muse ◕impact: −6.6 ms (~24% of startup)

Sixty validated help registrations plus the tip pool execute at source time, but are read only when zhelp/tips run. Pure data, no side effects — ideal candidates for the repo’s existing lazy-lib pattern. The compdef already falls back gracefully when the catalogue is absent.

Fix  Move data into lib/ files; source on first invocation from the commands and the compdef loader.
